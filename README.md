## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们同一份数据既有行式存储便于点更新，又有列式存储便于批量分析，两边经常对不上。请从零实现一个行列双存同步组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 行存支持按主键的插入、更新与删除，列存按批次重建；2) 同步策略：行存更新后异步把变更投递到列存，需说明延迟与一致的取舍；3) 支持一致性检查：定期比对一个范围内的行存与列存，输出不一致的主键与字段；4) 支持重建：列存某批次数据损坏时只重建该批次，重建期间查询仍可用（返回旧批次或标记为重建中）；5) 支持崩溃恢复：同步队列未消费完时崩溃，重启后必须补齐且不重复应用；6) 支持并发：行存更新与列存重建并发进行时，检查结果不得把正常延迟误判为不一致（需说明判定窗口）；7) 提供统计：同步条数、延迟分布、不一致条数与重建次数；8) 测试覆盖行存更新触发同步、一致性检查、批次重建、崩溃恢复补齐、并发误判避免与统计；`mvn -q verify` 一条命令跑通。
